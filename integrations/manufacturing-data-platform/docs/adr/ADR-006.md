# ADR-006: Use ClickHouse Cloud as PoC Deployment Model

## Status

**Accepted** — 2026-06-07

## Context / コンテキスト

The PoC requires a ClickHouse deployment for real-time operational analytics. ADR-002 selected ClickHouse as the real-time analytics engine; this ADR specifies the deployment model. The deployment must support Kafka Engine ingestion, sub-second queries, S3 tiered storage (for ONTAP S3 validation), and minimize operational overhead for a time-bounded PoC.

PoC にはリアルタイム運用分析のための ClickHouse デプロイが必要。ADR-002 は ClickHouse をリアルタイム分析エンジンとして選択した。本 ADR はデプロイモデルを指定する。デプロイは Kafka Engine 取り込み、サブ秒クエリ、S3 階層化ストレージ（ONTAP S3 検証用）をサポートし、期間限定の PoC に対する運用オーバーヘッドを最小化する必要がある。

## Decision / 決定

Use **ClickHouse Cloud** (free trial or development tier) as the PoC deployment model. If ONTAP S3 tiering validation requires VPC-local access to FSx for ONTAP endpoints, fall back to **ClickHouse BYOC** or **self-managed on EC2** for that specific test.

**ClickHouse Cloud**（フリートライアルまたは開発ティア）を PoC デプロイモデルとして使用する。ONTAP S3 階層化検証が FSx for ONTAP エンドポイントへの VPC ローカルアクセスを必要とする場合、その特定テストに限り **ClickHouse BYOC** または **EC2 セルフマネージド** にフォールバックする。

## Rationale / 根拠

### Why ClickHouse Cloud is preferred for PoC / PoC で ClickHouse Cloud が最適な理由

1. **Zero operational overhead** [確認済み]: No cluster provisioning, patching, scaling, or backup management. PoC team focuses on data pipeline validation, not infrastructure ops.

2. **Fastest time to value** [確認済み]: Sign up → create service → run queries in < 30 minutes. Free trial provides $300 credits (sufficient for 1-month PoC). (Source: clickhouse.com/pricing)

3. **Kafka Engine built-in** [確認済み]: ClickHouse Cloud supports Kafka Engine tables natively. No additional connector installation required. (Source: REF-034, ClickHouse docs)

4. **Manufacturing reference case** [確認済み]: Critical Manufacturing case study (REF-030) runs on ClickHouse Cloud. EMQ IIoT case (REF-032) uses ClickHouse Cloud for high-throughput industrial analytics.

5. **S3 tiered storage** [確認済み]: ClickHouse Cloud manages S3-backed storage automatically. For custom S3 endpoints (ONTAP S3 tiering test), custom storage policies may require BYOC or self-managed.

6. **AWS Marketplace availability** [確認済み]: Available via AWS Marketplace for consolidated billing. (Source: REF-045)

### Why not BYOC as primary / BYOC を主要にしない理由

- BYOC adds 1-2 days setup time (EKS provisioning, IAM configuration)
- BYOC has higher baseline cost (EKS control plane + worker nodes)
- BYOC is appropriate for production or compliance-constrained environments, not a PoC

### ONTAP S3 Tiering Consideration / ONTAP S3 階層化に関する考慮

[前提] ClickHouse Cloud connects to external S3 endpoints via PrivateLink. ONTAP S3 (FSx for ONTAP) is reachable from ClickHouse Cloud only if PrivateLink is configured. If latency or access issues arise during the ONTAP S3 tiering test (TSK-013), the fallback plan is:

1. Test ONTAP S3 tiering on a temporary self-managed EC2 ClickHouse instance (same VPC as FSx for ONTAP)
2. Use the result to validate the pattern
3. Keep ClickHouse Cloud as the primary analytics platform for all other tests

## Consequences / 結果

### Positive / ポジティブ

- PoC can start immediately without infrastructure provisioning
- No operational burden during PoC
- Automatic scaling handles variable synthetic workload
- Built-in monitoring and query insights
- Free trial credits cover PoC duration

### Negative / ネガティブ

- ONTAP S3 tiering test may require separate deployment (network access constraint)
- Less control over storage policies compared to self-managed
- ClickHouse Cloud pricing after trial may not represent production cost accurately
- Cannot access ClickHouse Cloud internals for deep performance debugging

### Neutral / 中立

- Network connectivity to MSK requires PrivateLink setup (same for Cloud and BYOC)
- ClickHouse Cloud uses S3 as backend by default (validates S3-backed architecture)

## Risks / リスク

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| ClickHouse Cloud cannot reach ONTAP S3 endpoint | Medium | Low (stretch goal) | Fallback to EC2 instance for tiering test only |
| Free trial credits exhausted before PoC complete | Low | Medium | Monitor usage; dev tier is ~$0.17/hour when active |
| Kafka connectivity to ClickHouse Cloud blocked | Low | High | MSK PrivateLink or public endpoint with SASL_SSL |
| ClickHouse Cloud region unavailable (ap-northeast-1) | Low | Medium | Use us-east-1; or BYOC in target region |
