# Shared Test Data

Shared test event data compatible with both Edge-to-Cloud and Lakehouse projects.

## Source

Test events are generated by the Edge project's `synthetic_events.py`:
- Repository: [ONTAP-Edge-to-Cloud-AI](https://github.com/Yoshiki0705/ONTAP-Edge-to-Cloud-AI)
- Generator: `synthetic_events.py`

## Schema

All test events conform to the **Unified Event Envelope v2.0.0**.
See: [14_edge_lakehouse_sync.md](../../docs/ja/14_edge_lakehouse_sync.md#11-統一イベントスキーマ-v200)

## Usage

### Lakehouse E2E Tests

```python
import json
from pathlib import Path

# Load sample events
samples_dir = Path(__file__).parent / "samples"
events = [json.loads(f.read_text()) for f in samples_dir.glob("*.json")]

# Use in Spark tests
df = spark.createDataFrame(events, schema=event_envelope_schema)
```

### Generating New Test Data

From the Edge project root:

```bash
python synthetic_events.py \
  --count 100 \
  --output ./samples/ \
  --event-types sensor_event,quality_event,payload_arrival \
  --site-id lab-tokyo
```

## Governance: Synthetic Data Flag

All synthetic test events carry `_synthetic: true` in the event envelope.
Downstream pipelines (ClickHouse `feedback_events.is_synthetic`,
Bronze `feedback_events.is_synthetic`) preserve this flag so synthetic
records can be excluded from production accuracy metrics if needed.

## Sync Source

Edge project: `tests/sample_events/` (21 files + feedback_event samples confirmed)

Includes `feedback_event_samples.jsonl` (3 events). All synthetic events carry
the `_synthetic: true` flag (governance requirement).

To import:
```bash
# From Lakehouse project root
EDGE_REPO="../ONTAP-Edge-to-Cloud-AI"
cp ${EDGE_REPO}/tests/sample_events/*.json \
   integrations/manufacturing-data-platform/poc/shared-test-data/samples/
cp ${EDGE_REPO}/tests/sample_events/*.jsonl \
   integrations/manufacturing-data-platform/poc/shared-test-data/samples/
```

## Sync Procedure

1. Generate test data in Edge project
2. Copy relevant samples to `poc/shared-test-data/samples/`
3. Verify schema compatibility: `python -c "import json; ..."`
4. Commit to both repositories
